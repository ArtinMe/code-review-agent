        Why this is a demo
        
      
        The live reviewer on the home page is real and runs on one free model. Running two frontier models against each other would be paid for on every click.
        
      
        
        
        
          What it would cost
          
        One review in this design makes about 14 model calls across two paid APIs: 8 to review, 2 to cross-examine, up to 2 for rebuttals, and 2 to agree on the patch. Neither API has a free tier, so a public link would bill whoever hosts it for every visitor.
        
        
        
        
        
          What's real and what's scripted
          
        Real: the protocol, and the rules for keeping, dropping and disputing findings. Scripted: every message on this page, written to show how those rules play out on the sample code.
        
        
        
        
        
          The protocol
          
          
            
        1. Each model runs the four reviewers on its own, without seeing the other's answers.
          2. 
            
        2. Each model reads the other's findings and accepts or rejects each one, with a reason.
          3. 
            
        3. A rejected finding's author gets one rebuttal: concede, or defend once.
          4. 
            
        4. Accepted findings form the report. Conceded ones are dropped. The rest are shown as disputed.
          5. 
            
        5. Both models agree on one patch for the accepted findings. It must parse, and it may not guess names the file doesn't contain.
          6. 
          
        
          
        The rounds are fixed, so cost and time are known in advance. Models never argue until they happen to agree.
        
        
        
        
        
          How it becomes real
          
        The pipeline already talks to models through one small interface, so Claude and GPT would be two new clients. It ships only if it measurably helps: on the evaluation set, one model today raises a false alarm on 2 of 4 clean files. Cross-examination has to bring that down.

    How a review works

    Models sometimes cite lines that don't exist or point at the wrong one. The steps after the reviewers are plain code, so the same input always gives the same report.

    1. Read in parallelFour reviewers, each with a narrow brief, read the same numbered code at once.
    2. Check against the codeA finding survives only if its quoted code is on the cited lines, or within three lines, where it's re-anchored.
    3. Merge duplicatesWhen two reviewers flag the same lines for the same reason, they become one finding with higher confidence.
    4. Rank and scoreFindings are ordered by severity times confidence, and the score is a fixed formula, not a model's opinion.
